# Content Editing Guide

Most visible text is editable from these files:

- `src/data/siteContent.ts`: site-wide text, navigation, hero, section labels, contact links, footer, post UI labels
- `src/data/projects.ts`: project titles, descriptions, tags, stack, links, status
- `src/data/experience.ts`: education, lab, conference, and career items
- `src/data/publications.ts`: publication titles, tags, year, URL
- `src/content/posts/*.mdx`: blog post title, date, tags, summary, and body

For layout and visual style, edit:

- `src/index.css`: colors, spacing, typography, cards, hero, project layout

The main portfolio flow is:

1. Hero
2. Featured systems
3. Research direction
4. Experience
5. Publications
6. Stack
7. Writing
8. Contact
